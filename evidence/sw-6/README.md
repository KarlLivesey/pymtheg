# SW-6 installed TypeScript refresh

[Change note](../../docs/changes/SW-6.md) · [Coverage plan](../../docs/coverage-plan.md) · [Archive](coverage-plan-input.json.gz)

This sweep measures main `2dc05bebd4d38fc44075c98637a58c15bd614ba3`, which
includes C-30, C-32 and C-33. The build used Node 24.21.0 on the dev server,
on 22 November 2026. Only the installed TypeScript mode was run: all 20
TypeScript pins from `sweep/repos.json`, with the SW-5 runner and policy.
That policy means:

- the declared package manager with its frozen lockfile, and lifecycle
  scripts disabled;
- indexing inside a network namespace with no network access;
- a 60-minute budget per pin;
- three workers, with microsoft/TypeScript, pingdotgg/t3code and
  vercel/turborepo run alone.

The bare, offline-Go-toolchain and source-review parts of the archive are
SW-5's, which are SW-4's measurements, unchanged.

## Files

- `coverage-plan-input.json.gz`: the SW-5 archive with all 20 installed
  TypeScript receipts replaced by this sweep's
  (`refresh-evidence.mjs overlay-installed`). The plan is regenerated from it.
- `attempts.md`: every attempt in the archive, with wall time and peak memory,
  as generated by `coverage.mjs --attempts`.
- `remaining-sites.json`: for every first stored blocker of the TypeScript
  links below Level 2, the exact count, its pins and link kinds, and the 10
  lowest-ranked sites at seed `pymtheg-sw6-2026` with source excerpts.
  Excerpts go through the exporter's privacy filter (`draw-installed.mjs`).
- `candidate-split.json`: candidate-set links split by what their candidates
  are (`candsplit.mjs`).
- `failed-program-split.json`: links in the large groups split by whether
  their compiler program contained a failed file (`extsplit.mjs`).
- `verdicts.json`: the hand-entered shape and provability verdict for each
  group, from reading those sites.
- `plan-sw6.mjs`: the plan post-step. It renders the remaining-work list,
  marks Go and Rust as unchanged since SW-5, and points the evidence links
  at SW-6.
- `pintable.mjs`: the per-pin table below, comparing the SW-5 and SW-6
  archives. `pinscore.mjs` recomputes one pin's figures directly from its
  graph.

## Outcomes

19 of 20 pins finished the installed graph and the sweep queries.

- **microsoft/TypeScript** installed, then reached the 60-minute limit
  during cold indexing (`graph analyze typescript: 0/27194`, exit 137, peak
  4,952 MiB). This was one attempt, as asked. Its receipt contributes no
  TypeScript links. C-26 (the analysis watchdog for this pin) merged after the measured
  commit, so this outcome predates it.
- **vercel/turborepo** finished the full mixed-language sweep, with all
  languages, in 1,755 s (cold index 1,272 s, peak 5,529 MiB), inside the
  limit. Its TypeScript graph has 53,495 links at 46.98% Level 2 (30.61%
  proven, 16.37% assumption-marked), with 26 failed files. At SW-5 the same
  pin contributed no TypeScript links.

## Reproduce

On the dev server, from a build of the measured commit:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
node scripts/sweep/run.mjs --local-build . --installed --output "$PYM_SCRATCH/installed-run.json" \
  --parallel 3 --serial-pin microsoft/TypeScript --serial-pin pingdotgg/t3code --serial-pin vercel/turborepo
node scripts/sweep/refresh-evidence.mjs export
node scripts/sweep/refresh-evidence.mjs overlay-installed --base evidence/sw-5/coverage-plan-input.json.gz \
  --commit 2dc05bebd4d38fc44075c98637a58c15bd614ba3 --output "$PYM_SCRATCH/coverage-plan-input.json.gz"
node evidence/sw-6/draw-installed.mjs "$PYM_SCRATCH/installed-run.json" remaining-sites.json 10
node evidence/sw-6/candsplit.mjs "$PYM_SCRATCH/installed-run.json" > candidate-split.json
node evidence/sw-6/extsplit.mjs "$PYM_SCRATCH/installed-run.json" external no-symbol any-receiver local "(unit only)" "(candidate set)" > failed-program-split.json
```

Then, from the repository root, regenerate the plan:

```sh
node scripts/sweep/coverage.mjs --results evidence/sw-6/coverage-plan-input.json.gz --plan docs/coverage-plan.md
node evidence/sw-6/plan-sw6.mjs docs/coverage-plan.md
```
