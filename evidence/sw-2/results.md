# SW-2 pilot: full result tables

Generated by `scripts/compare/run.mjs` (`summary.md` in its output folder),
copied here unchanged apart from headings. Buckets:

- `all`: every tool that ran has the link.
- `only:<tool>`: only that tool has it; `only:pymtheg:definite` and
  `only:pymtheg:candidate` split Pymtheg's by certainty.
- `others-not-pymtheg`: at least one other tool has it and Pymtheg does not;
  `pymtheg-missing-vs:<tool>` per other tool.
- `others-missing:<tool>`: Pymtheg has it and that tool does not.
- `pymtheg-candidate-others-have`: Pymtheg has it only as a candidate-set
  member and another tool has it as a single target.

"Pymtheg at the sites…" lists what Pymtheg has where another tool has a link
and it does not (see `absentState` in `scripts/compare/README.md`).
A tool run that crashed is shown in the table and left out of the diff.
