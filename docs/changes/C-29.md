## Resolution and diagnostics

Shared `core` declarations use the existing edition tables and lexical
checks. When a crate can select `no_std`, the graph can record the shared
prelude type, value, variant, derive or macro. Names such as `String` and
`vec!` need a binding valid for every build. The two `panic!` macros have
different declarations. `no_implicit_prelude` and possible `no_core` also
withhold credit. Known standard-library import namespaces and selected exact
registry releases supply more named imports. The target uses the public
spelling in the library, including any re-export path. The Rust module version
is 41 so existing stores re-index.
