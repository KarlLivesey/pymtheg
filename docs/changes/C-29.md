## Resolution and diagnostics

Shared `core` declarations use the existing edition tables and lexical
checks. When a crate can select `no_std`, the graph can record the shared
prelude type, value, variant, derive or macro. Names such as `String` and
`vec!` need a binding valid for every build. The two `panic!` macros have
different declarations. `no_implicit_prelude` withholds implicit prelude
credit. A possible `no_core` withholds both implicit sysroot and prelude
targets. A written `extern crate` can still supply an explicit binding.
Known standard-library import namespaces and selected exact
registry releases supply more named imports. The target uses the public
spelling in the library, including any re-export path. The Rust module version
is 42 so existing stores re-index. [Rust prelude reference](https://doc.rust-lang.org/reference/names/preludes.html#standard-library-prelude) · [Standard prelude source](https://github.com/rust-lang/rust/blob/1.98.1/library/std/src/prelude/v1.rs) · [Core prelude source](https://github.com/rust-lang/rust/blob/1.98.1/library/core/src/prelude/v1.rs)

### Rustls phase disagreement

The first candidate left 37 Rustls links without an explanation. Analysis
found checkout targets for all 37. Final resolution withheld 34 imports when
it treated the inferred `?module-layout` marker on a file as a written inner
`cfg` on its module declaration. Three local references lost their anchor
when that same import lookup stopped. Replaying the final lookup with the
same facts in three link orders reproduced the refusals.

The fix keeps the marker out of the declaration's file-configuration
comparison. The directory-uncertainty checks still apply to lookups through
guessed placements. A separate fixture places the same filename under a
known declaration and a guessed path. The fixture failed before the fix.
The final Rustls index resolves all 37 traced sites.
The import and glob-cycle changes in PR 33 are independent of this fix.

## Review follow-up

The pinned Rust compiler returned E0433 for both implicit sysroot imports
under `#![no_core]` and accepted the explicit `extern crate core` control.
The graph fixtures also cover a conditional `no_core` and a site gated
to a configuration with the ordinary prelude available.

The ten-pin replay checked all 1,042 links previously labelled
`local-pattern-binding-unverified`. It moved 122 to
`crate-placement-unavailable`, including the use of `end` at Rustls
`admin/threads-seq.rs:44`. Another 130 links now record
`macro-use-exports-unverified` in place of `competing-macro-import`.
The compiler accepted a dependency exporting only `ping!` together
with the built-in `Default` derive.

The Rustls replay produced 2,876 diagnostic text differences from its stored
reviewed graph. Replaying both builds with identical inputs isolated the
follow-up to the 11 placement relabels on that pin.

All 486,329 corpus link outcomes and targets match the reviewed build.
The repeat against main also preserves all 92,306 definite targets across
the same three pins. [Replay counts](../../evidence/c-29/review-fixes.json)
