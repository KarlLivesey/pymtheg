# C-1 Rust lookup completion and cancellation

A Serde profile traced the stall to the source resolver revisiting incomplete
names along overlapping glob and re-export paths. Conditional module layouts
added more paths into the same searches. The existing cycle checks stopped
individual loops, while each caller could still repeat a large part of the same
search.

Rust now reuses an incomplete lookup within the same resolver invocation when
the namespace, module placement, configuration and inspected ancestor tests
match. Results that used different cycle cuts are evaluated again. The stored
result retains its target hints, failure causes and uncertainty. The resolver's
existing import depth boundary now records `import-lookup-depth-unverified`.
Rust module version 28 refreshes this diagnostic in existing indexes.

Rustls also exposed repeated textual macro lookup work. One file contributed
244,628 unseen macro entries with 786 distinct records. The resolver now
indexes textual macros by file and retains one copy of each identical unseen
entry, preserving its position, conditions and reason.

For cancellable graph requests, the Rust analyzer and resolver run in owned
workers. The coordinator handles SIGINT or SIGTERM and awaits termination of
the worker. File and unresolved link rows already written may remain, with
no completion checkpoint, so `graph status` and `--no-sync` queries report
`sync.complete: false` and warn `index-incomplete`. The next sync repairs
the index and produces the same graph as a clean index.

The workers receive captured facts and use the same source resolver. The
analysis pass still attaches presence and uncertainty to parsed facts, and
resolution still reads the analyzed facts to produce stored targets and
derived links.

The first candidate sweep finished indexing Serde, Rustls, Dioxus and
Embassy. The eight graphs used for comparison retained all 349,441 stored
links. The profiled C-1 SWC run reached `graph analyze rust: 1523/1523`, and a
sample after that marker was dominated by SQLite writes of analyzed facts.
The review rerun ended at `graph analyze rust: 0/1523`, with most of its
observed time spent on initial SQLite writes. Both runs reached the wall
limit, leaving full cold-index and Rust resolution times unmeasured. In the
sweep after merging PR 9, Embassy reached the wall limit after Rust analysis completed (the last progress marker was `graph analyze rust: 2514/2514`; which step was in progress at the deadline was not profiled).
