# C-38A: an index run claims the store before analysis; the report names the analysis path

Split from C-38 (pull request 50), which keeps the TypeScript scoped
re-index. This part needs no scoped path.

## The run's early claim

Two indexers can run against one store (C-22): the first to write takes
the store, and a run that finds another run's write since it began stops
and writes nothing. A module whose parsed writes wait for its analysis
(Go and Rust, C-27) did not write before analysing, so a run that began
during that analysis found the store unchanged since its own start. It
answered without writing, and the first run then wrote its analysis of the
older text.

Now the run claims the store as soon as any module holds back edited files'
writes, before analysis (`indexer.ts`, `store.claimIndexRun`): it writes its
run mark in its own committed transaction, outside the write batches of
C-37 (inside a batch the claim would commit only when the batch scope
ends). A run that begins during the analysis then sees the claim, takes
over, and the first run writes nothing more.

Test: `test/graph-index-runs.test.mjs`, "Go: A analyses with an export
removed and pauses; it is restored; B completes; A resumes and writes
nothing". On main it fails (A writes its stale analysis after B); with the
claim, A rejects, the rows equal B's, and one more index equals a cold
index.

## The analysis path in the index report

The index result's report gains `analysisPaths`: per module that reports
one, the path its analysis took, and the CLI prints it
(`Analysis typescript: full (no previous index)`). TypeScript reports
`reused` when it builds no program (its stored results stand) and `full`
otherwise, with the note `no previous index` on a first index. Without a
scoped path (C-38) it never says anything else. A module reports a path
only if it declares `reportsAnalysisPath` (it must analyse in this process:
a context cloned into a worker cannot carry the report function); Go and
Rust do not report one yet.

Test: `test/graph-typescript-analysis-path.test.mjs` (first index, an
unchanged re-index, an edit).

No stored row changes, so no module version changes.
