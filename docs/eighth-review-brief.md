Changed journeys to challenge:

1. Check a selected file in a large project: imports and reverse callers, unrelated
   broken/undecodable/unreadable material, inventory paging and on-demand file loads.
2. Search types/callables under a misleading root name; use relative IDs after
   moving the project. Keep unsaved checks and signature previews useful for agents.
3. In one refresh move a document and replace its old path; verify the plan's
   target, old/current text, content review, whitespace policy and stale evidence.
4. Maintain handwritten TypeScript/Rust/Go implementations against regenerable
   contracts. Compare saved manifests. Challenge plugins, omissions, invalid
   manifests, source changes during preview and large/recursive type shapes.
5. Resume a saved form after a body edit, a signature change and a rename/removal.
   Ensure a first-time user can see and preserve both versions without losing work.
6. Review/withdraw a separate branch with reviewer/notes, restart and merge older
   history. No stale import may revive a withdrawn review or imply a merge.
7. Inspect output vocabulary, internal search noise, changed-type comments,
   formatter layouts, empty-state contrast, narrow layout and agent setup.
8. Re-run the existing architecture imports/recovery/conflict journeys and real
   backend counterexamples. Look for regressions caused by these fixes.
